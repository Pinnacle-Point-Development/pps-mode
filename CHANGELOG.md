# Changelog

## 0.0.1 — 2026-09-28

- Define the safe, versioned PPS 1 spreadsheet format.
- Add the keyboard-first Emacs grid editor and retro COLORMODECTL display.
- Add formulas, multiple sheets, structural editing, sorting, filtering,
  selection operations, undo/redo, validation, and CSV/TSV interchange.
- Preserve normal Emacs save, backup, locking, revert, and auto-save behavior.
- Include a GNU Info manual covering installation and everyday operation.
